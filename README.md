Tecmo Arcade for MiSTer FPGA
By Josh Bassett
Ported to Game Bub by: Toady M

The Tecmo arcade core for MiSTer FPGA brings three beloved arcade titles from the 1980s to modern FPGA hardware: Rygar, Gemini Wing, and Silkworm. Rather than running the games through conventional software emulation, the core recreates the original arcade hardware using programmable logic, allowing the MiSTer to reproduce the behavior of the original machines.

The project is part of the MiSTer FPGA preservation community, whose goal is to keep classic arcade and console hardware accessible and playable for future generations. Now ported to the Game Bub FPGA Handheld.


Rygar (1986)
Gemini Wing (1987)
Silkworm (1988)

Development and credits

The MiSTer Tecmo core was created by Josh Bassett, who published the project in 2020.
Ported By Toady M in 2026

The core uses MiSTer's MRA arcade game definitions and compatible MAME ROM sets. The required game ROMs are not included with the core and must be supplied separately.
